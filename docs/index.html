REFERENCE CIRCUIT

回路の形と、安全と言える範囲を同じ場所に置く

36キーJapanese duplex matrix、GPIO0–11、8P8C pinout、470 Ω、 TPD4E05U06DQAをKiCad 10へ実装しました。ERCだけでなくXML netlistを検査し、 中央電源の混入と抵抗値の変更をnegative testで拒否します。

中央無給電

pin 1/8はGND、pin 2–7は右matrix信号です。VCC、VBUS、5V、3V3、RAWは禁止します。

故障電流を低減

6本へ470 Ωを入れ、モデル上の単線GND故障を6.666 mAへ抑えます。GPIO無損傷の保証ではありません。

PoEは保護対象外

24 Vでも470 Ωは約1.23 W相当です。SPLIT ONLY / NO LANと専用ストレートケーブルを必須にします。

回路と故障分析を読む ADR 0003を読む

REPRODUCIBLE FIRMWARE

固定QMK commitからRP2040 UF2を作る

3 × 12の論理matrixとして左右36キーを走査します。QMK split transportや 中央ケーブルの電源railは使わず、GP0–GP11を参照回路と一致させます。

Japanese duplex

Bankごとに方向を切り替え、全6線を入力pull-upへ戻してから1本だけLow駆動します。

固定して再現

QMK本体を完全なcommit SHAへ固定し、ローカルとCIで同じoverlayをlint・compileします。

証拠を分離

UF2生成は合格済みです。実キー、ghosting、活線挿抜は後続Issueで検証します。

DECISIONS

  • 36キー、片側3×5+3
  • Kailh PG1350（Choc v1）

EVIDENCE BOUNDARY

文書、シミュレーション、実機を混同しない

まだ「安全」とは断定しません

中央ケーブルに電源線がないことは、TRRS型のVCC–GND短絡経路を減らします。 ただし、活線挿抜、ESD、誤配線、PoE誤接続への耐性は別の試験が必要です。 PCのUSBポートを故障注入試験には使用しません。
