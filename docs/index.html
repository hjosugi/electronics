DECISIONS

初号機で固定するもの、利用者が変えられるもの

固定する構造

  • 36キー、片側3×5+3
  • Kailh PG1350（Choc v1）
  • 横18 mm、縦17 mmピッチ
  • 単一平面PCB、エンコーダなし

調整できる配置

  • column stagger
  • 各列±3°以内のsplay
  • 親指3キーの位置と角度
  • 左右間隔120–260 mm、yaw 0–15°

ケースで選ぶ姿勢

  • tenting 0°、10°、20°
  • 左右を肩幅に合わせて配置
  • 平面PCBを先に検証
  • true keywellはIssue #16で比較

EVIDENCE BOUNDARY

文書、シミュレーション、実機を混同しない

まだ「安全」とは断定しません

中央ケーブルに電源線がないことは、TRRS型のVCC–GND短絡経路を減らします。 ただし、活線挿抜、ESD、誤配線、PoE誤接続への耐性は別の試験が必要です。 PCのUSBポートを故障注入試験には使用しません。
