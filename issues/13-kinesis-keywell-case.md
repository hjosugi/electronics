# [case] Kinesis系keywellと調整式tentingを実機比較する
Labels: hardware,test

## 背景
ADR 0002では、Kinesisの左右分離、縦列、親指分担、tentingという原則を採用した。一方、初号機の単一平面PCBではconcave keywellを再現できない。

人体工学的な特徴を外観だけで模倣せず、平面PCB + wedgeと、スイッチ面を三次元化する方式を別々に比較する。

## やること
- 平面PCB + 交換式wedge、分割小基板、フレキシブルPCB、手配線/別体プレートの構成を比較する
- 初号機の平面PCBケースで0°、10°、20°のtentingを安全に切り替える機構を作る
- 左右間隔120–260 mm、half yaw 0–15°の机上配置を妨げないケーブル出口と滑り止めを設計する
- true keywellへ進む場合は、曲率、列高、親指クラスタ、配線、組立公差をパラメータ化する
- 1:1モックと試作で到達性、キーキャップ干渉、ぐらつき、ケーブル曲げ、ケース強度を記録する
- CAD、生成手順、第三者部品の由来とライセンスを`case/`と`docs/`へ保存する

## 安全境界
- Kinesis製品と同等の医学的効果や適合を主張しない
- 痛みやしびれを実験継続の判断材料にせず、使用を止めて作業環境を見直す
- true keywellで配線方式や中央接続が変わる場合、回路IssueとADRを先に作る
- 中央8P8Cへ`VCC/5V/3V3/RAW`を追加しない

## 完了条件
- 少なくとも平面PCB + wedgeとtrue keywell候補1方式の比較ADRがある
- 0°、10°、20°の各tentで、荷重時の安定性とキー/ケース/ケーブル干渉を実測している
- 2種類以上の利用者プロファイルを1:1モックまたは試作へ反映し、変更値と所感を匿名で記録している
- 採用方式のCADソース、再生成手順、ライセンス、写真、測定値が公開されている
- 不採用方式と再検討条件が文書化されている
