# [hw] RJ45 中央接続 + 保護回路
Labels: hardware,safety

## 背景
中央ケーブルには VCC を流さない。GND + マトリクス信号のみ。活線挿抜を「仕様として許容」するための保護をここで確定する。

## やること
- 8P8C pinout を確定 (信号 6-7 本 + GND。GND を複数ピンに割るかも決める)
- コネクタへ出る全 GPIO に直列抵抗 220-470Ω (値は issue #09 のシミュレーションで確定)
- RJ45 直後に低容量 TVS アレイ (4ch x2) を検討。3.3V 系向けの型番を選定し、容量が信号波形に与える影響も #09 で見る
- シルクに `SPLIT ONLY / NO LAN` を明記。ストレートケーブル指定
- 誤挿入の机上検討: LANポート、クロス結線、PoEへ誤接続した場合の危険を分析する。安全を実証できない接続は`禁止`と明記し、機器を使った破壊試験は行わない

## 完了条件
- pinout 表 + 保護部品の型番が確定し docs/ にある
