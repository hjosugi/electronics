# GitHub Issues原稿

今後の回路、ファームウェア、検証作業を、背景、作業内容、完了条件付きで管理するための原稿です。番号順に依存関係を読みやすくしています。

公開リポジトリへ一括登録するには、GitHub CLIで認証した状態で次を実行します。

```bash
./scripts/import_issues.sh hjosugi/electronics
```

スクリプトはラベルを作成し、ファイル名順にIssueを登録します。同じタイトルが既に存在する場合はスキップするため、途中失敗後も再実行できます。

Issue本文をGitHub上で更新した後は、この原稿側にも重要な設計判断を反映してください。最終的な設計判断と実測値はIssueだけに閉じ込めず、`docs/adr/`または検証報告書へ残します。
